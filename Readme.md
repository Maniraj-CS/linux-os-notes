# Introduction to Linux

Linux is a free, open-source operating system kernel that acts as the core bridge between a computer's physical hardware and its software programs.

## Unix vs Linux

### Cost and Licensing

Unix: Closed-source and commercial. Users must purchase expensive licensing fees from specific vendors to run official Unix distributions.

Linux: Open-source and free. Anyone can download, use, view, and modify the source code without paying a fee.

### Distributions and Variations

Unix: Limited variations controlled by specific vendors, such as Oracle Solaris and HP-UX.

Linux: Hundreds of community-driven variations called "distros," including Ubuntu, Fedora, Debian, and Mint.

### Hardware and Flexibility

Unix: Typically tied to high-end enterprise servers, mainframes, and specific hardware architectures.
Linux: Highly portable and lightweight, running on everything from tiny embedded devices and Android smartphones to personal laptops and supercomputers
